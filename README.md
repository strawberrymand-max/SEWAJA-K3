# SEWAJA — Sistem Informasi Penyewaan iPhone & Kamera

**SEWAJA** adalah aplikasi berbasis *Command Line Interface* (CLI) menggunakan bahasa pemrograman Python dan library `pandas` untuk mengelola sistem penyewaan unit iPhone dan Kamera. Program ini dilengkapi sistem penyimpanan data berbasis CSV (`users.csv`, `katalog.csv`, dan `transaksi.csv`) dengan pembaruan stok otomatis.
